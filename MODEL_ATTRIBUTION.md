# Demonstration model attribution

The visual vehicle model shown in `demo/axabraCFD.mp4` and `demo/preview.jpg` is:

- **Title:** [2024 Porsche 992 GT3 R](https://sketchfab.com/3d-models/2024-porsche-992-gt3-r-b76c9b2ae2d548c3869426eac4ab8a19)
- **Creator:** [Dave Love / Tyler_Dave](https://sketchfab.com/Tyler_Dave)
- **Platform:** Sketchfab
- **License:** [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/)

The model is used here as a visual asset in the AXABRA CFD interface. Its presentation is changed through rendering, scalar colouring and airflow overlays. The original model file is not redistributed in this repository.

This visual model should not be treated as a watertight or calculation ready CFD body. A model can render correctly while still containing openings, intersections, inconsistent normals or topology that prevents reliable meshing.
